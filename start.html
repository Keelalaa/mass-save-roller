⚔️ Mass Save Roller

Roll saving throws for a whole pile of monsters at once. You type the DC, the modifiers and the damage — it does the rest.

Just want the website?

Open the website

Works on its own — no add-on needed if you roll on the website.

Using it with Roll20 — nothing to install

Drag this gold button up onto your bookmarks bar (press Ctrl+Shift+B if you don't see the bar):

⚔️ Mass Save

Then, in your Roll20 game, click the ⚔️ Mass Save bookmark. The roller opens in a new tab, linked to Roll20.

Want both side by side? Drag the roller's tab out of Chrome. Have an older ⚔️ Mass Save bookmark that opens a window? It still works. To get tabs instead, delete it and drag this one up.

Click it once each time you open or reload Roll20. Changing maps is fine.

How a mass save goes

  1. In the roller click + Add enemy group and name it.
  2. In Roll20, select that group's monster tokens. On the card click ⬇ Add selected Roll20 tokens. Forgot one? Select it and click again. Tokens with no name or the same name get numbered in Roll20, like Cat 1 and Cat 2. Players still only see a nameplate if they could before. Type their save modifiers (once), the DC and the damage.
  3. Click Start. Click the 📋 Copy button it shows, like /r 8d20 (one d20 per monster), then paste it into Roll20 chat and send it.
  4. Done — passes and fails are worked out and the selected tokens' HP goes down in Roll20. A roll never touches tokens you didn't select.
  5. Need to change one token by hand? Type its HP, max or temp HP on its row, or use − and +. You don't need to select it for that.

Spell leaves a condition on a fail, like Synaptic Static? Tick Lasting condition on a failed save and pick the icon. Show all icons opens the full list, with a search box. Selected tokens that fail get it in Roll20, and Undo roll takes it off again.

Tokens you made from your own images work too — if their HP bar is empty, the roller fills it in with “HP each”.

Rolling initiative for all of them

  1. Type the bonus in the Initiative + box, right above the Start button in the Initiative section. It goes back to 0 after each roll.
  2. In Roll20, select the tokens that are rolling. Click ⚡ Start initiative. Click the 📋 Copy button it shows, like /r 8d20 (one d20 per monster), then paste it into Roll20 chat and send it.
  3. Rolling /r 8d20+3 works too: the +3 goes on each monster, instead of the box's number.
  4. Need to change a number? Change it in Roll20's Turn Order window and the roller's list updates too.
  5. Done — each selected token goes on Roll20's Turn Order with its own number. Anyone already on it keeps their spot and number. Tokens you didn't select are never added.
