⚔️ Mass Save Roller

Roll saving throws for a whole pile of monsters at once. You type the DC, the modifiers and the damage — it does the rest.

Open the website

Works on its own — no add-on needed if you roll on the website.

Using it with Roll20 (one-time setup, ~1 minute)

⬇ Download the Roll20 add-on
  1. Open the downloaded file and drag the roll20-addon folder onto your Desktop (or anywhere you'll keep it).
  2. In Chrome, open chrome://extensions (copy it into the address bar).
  3. Turn on Developer mode (top-right switch).
  4. Click Load unpacked and pick the roll20-addon folder.
  5. Open your Roll20 game, then the website. Tick Roll the d20s in Roll20.
  6. First time only: the website shows Set it up (one time) — click it, then click Install it for me on the Roll20 page that opens.

How a mass save goes

  1. In Roll20, select the monster tokens caught in the spell.
  2. On the website click ⬇ Get selected tokens, type their save modifiers (once), the DC and the damage.
  3. Click Start, then in Roll20 type /r 8d20 (one d20 per monster).
  4. Done — passes and fails are worked out and the selected tokens' HP goes down in Roll20. Tokens you didn't select are never touched.
